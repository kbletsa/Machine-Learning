# Machine Learning Projects Portfolio

This repository contains a collection of 10 Machine Learning projects implemented in Python using Jupyter Notebooks. The projects cover a wide range of topics from basic regression and classification to advanced Deep Learning techniques.

## Project List

* **Project 1:** Implements a Linear Regression model to predict housing prices based on socio-economic and location features.
* **Project 2:** Performs binary and multiclass classification on the MNIST handwritten digit dataset using Stochastic Gradient Descent (SGD).
* **Project 3:** Explores advanced regression techniques, including Support Vector Regression (SVR) and Random Forests, with hyperparameter tuning via Grid Search.
* **Project 4:** Visualizes and trains Decision Tree classifiers on the Iris dataset, analyzing decision boundaries and model interpretability.
* **Project 5:** Demonstrates Ensemble Learning methods, such as Voting Classifiers, Bagging, and Random Forests, to improve prediction accuracy.
* **Project 6:** Applies Unsupervised Learning algorithms, including K-Means, DBSCAN, and Gaussian Mixtures, for clustering and image segmentation tasks.
* **Project 7:** Builds and trains a Multi-Layer Perceptron (MLP) neural network using TensorFlow/Keras to classify Fashion MNIST images.
* **Project 8:** Investigates Deep Learning optimization strategies, including Batch Normalization, Dropout, and Learning Rate Scheduling.
* **Project 9:** Implements Convolutional Neural Networks (CNNs) with pooling layers to achieve high accuracy in image classification tasks.
* **Project 10:** Utilizes Recurrent Neural Networks (RNNs), including LSTMs and GRUs, for time series forecasting and sequence processing.

## Technologies Used
* Python
* Scikit-Learn
* TensorFlow / Keras
* Pandas & NumPy
* Matplotlib & Seaborn
